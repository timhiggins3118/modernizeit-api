# Files API Documentation

**Date:** 2025-12-20
**Status:** Implemented
**Purpose:** File access for the Code Editor with COBOL (read-only) and Java (read/write) support

---

## Overview

The Files API provides file operations for the Code Editor view. It manages:
- **COBOL source files** - Read-only access to original source code
- **Java workspace files** - Read/write access to editable Java copies
- **Section mappings** - COBOL paragraph to Java method mappings
- **Workspace management** - Reset workspace from generated files

### Folder Structure

```
{account}/{app}/
├── shared/uploads/{hash}/extracted/COBOLSource/
│   ├── Cobol/           ← Main COBOL programs (.CBL)
│   └── Copybooks/       ← COBOL copybooks (.CBL, .cpy)
│
├── code_analysis/
│   ├── generated/{program}_cbl/   ← Original generated Java (BACKUP - never modified)
│   │   └── src/main/java/...
│   └── reports/
│       └── *_procedure_model.json  ← Section mapping data
│
└── workspace/java/{program}_cbl/  ← Working copies (EDITABLE)
    └── src/main/java/...
```

### Design Principles

1. **COBOL is read-only** - Source files are never modified
2. **Generated Java is preserved** - Original output is kept as backup
3. **Workspace for edits** - Users work on copies, can reset anytime
4. **Storage abstraction** - Works with both local filesystem and S3

## API Endpoints

### Base URL
```
/files/{account}/{app}
```

Where:
- `account` = Account ID (e.g., "0U812")
- `app` = Application name (e.g., "TestApp02")

---

### COBOL Endpoints (Read-Only)

#### List COBOL Files
```
GET /files/{account}/{app}/cobol
```

**Response:**
```json
{
  "files": [
    {
      "name": "IFPR321.CBL",
      "path": "cobol/IFPR321.CBL",
      "type": "file"
    }
  ],
  "total": 1
}
```

#### Read COBOL File
```
GET /files/{account}/{app}/cobol/{file_path}
```

**Example:**
```
GET /files/0U812/TestApp02/cobol/cobol/IFPR321.CBL
```

**Response:**
```json
{
  "path": "cobol/IFPR321.CBL",
  "content": "       IDENTIFICATION DIVISION.\n       PROGRAM-ID. IFPR321...",
  "size": 12345
}
```

---

### Java Endpoints (Read/Write)

#### List Java Files
```
GET /files/{account}/{app}/java
```

**Response:**
```json
{
  "files": [
    {
      "name": "Ifpr321.java",
      "path": "src/main/java/com/modernizeit/generated/Ifpr321.java",
      "type": "file"
    }
  ],
  "total": 1
}
```

#### Read Java File
```
GET /files/{account}/{app}/java/{file_path}
```

**Example:**
```
GET /files/0U812/TestApp02/java/src/main/java/com/modernizeit/generated/Ifpr321.java
```

**Response:**
```json
{
  "path": "src/main/java/com/modernizeit/generated/Ifpr321.java",
  "content": "package com.modernizeit.generated;\n\npublic class Ifpr321 {...}",
  "size": 5678
}
```

#### Save Java File
```
POST /files/{account}/{app}/java/{file_path}
```

**Request Body:**
```json
{
  "content": "package com.modernizeit.generated;\n\n// Updated code..."
}
```

**Response:**
```json
{
  "path": "src/main/java/com/modernizeit/generated/Ifpr321.java",
  "content": "...",
  "size": 5700
}
```

---

### Workspace Management

#### Get Workspace Status
```
GET /files/{account}/{app}/workspace/status
```

**Response:**
```json
{
  "has_generated": true,
  "has_workspace": true,
  "project_name": "ifpr321_cbl",
  "java_files": 5
}
```

#### Reset Workspace
```
POST /files/{account}/{app}/workspace/reset
```

Copies all files from `generated/` to `workspace/`, overwriting any user edits.

**Response:**
```json
{
  "success": true,
  "message": "Workspace reset to original generated code",
  "files_copied": 5
}
```

---

### Section Mappings

#### Get Sections
```
GET /files/{account}/{app}/sections
```

Returns COBOL paragraph/section to Java method mappings from `procedure_model.json`.

**Response:**
```json
{
  "sections": [
    {
      "cobol_name": "0000-MAIN-LOGIC",
      "cobol_start_line": 45,
      "cobol_end_line": 78,
      "java_method": "mainLogic",
      "java_class": "Ifpr321",
      "status": "converted"
    },
    {
      "cobol_name": "1000-INIT-ROUTINE",
      "cobol_start_line": 80,
      "cobol_end_line": 120,
      "java_method": null,
      "java_class": null,
      "status": "pending"
    }
  ],
  "total": 2
}
```

## Storage Configuration

### Local Storage (Default)
```json
// config/app_settings.json
{
  "storage_mode": "local",
  "base_local_path": "/path/to/modernizeit_output"
}
```

### S3 Storage
```json
// config/app_settings.json
{
  "storage_mode": "s3",
  "s3_bucket": "my-modernizeit-bucket",
  "s3_prefix": "modernizeit_output",
  "s3_region": "us-east-1"
}
```

### Environment Variables
```bash
STORAGE_MODE=s3
S3_BUCKET=my-bucket
S3_PREFIX=modernizeit_output
S3_REGION=us-east-1
```

## Error Handling

| Status Code | Description |
|-------------|-------------|
| 200 | Success |
| 404 | File or directory not found |
| 404 | No source files found (run ingest first) |
| 404 | No generated Java found (run code analysis first) |
| 500 | Server error (file I/O, S3 error) |
