## 3. Fixes Applied

### 3.1 Junk File Filtering

**Problem:** Mac OS artifacts (`__MACOSX/`, `.DS_Store`) were being extracted and processed.

**Solution:** Two-level filtering:

#### Level 1: Ingest (Primary)
**File:** `engines/ingest/ingest_upload_handler.py`

Added `_should_skip_file()` function:
```python
def _should_skip_file(filename: str) -> bool:
    """Filter out junk files during extraction."""
    # Mac OS resource forks
    if '__MACOSX' in filename:
        return True

    # Get just the filename part
    basename = filename.split('/')[-1]

    # Hidden files
    if basename.startswith('.'):
        return True

    # Windows thumbnail cache
    if basename.lower() == 'thumbs.db':
        return True

    return False
```

Applied to:
- `process_zip_upload()` - ZIP extraction
- `process_single_file_upload()` - Single file uploads

#### Level 2: Data Analysis (Safety Net)
**Files:**
- `engines/data_analysis/analyzers/regex_extractor.py`
- `engines/data_analysis/analyzers/ast_analyzer.py`

Same filtering for defense-in-depth (handles legacy data).

### 3.2 Copybook Parsing Fix

**Problem:** Copybooks lack section headers (WORKING-STORAGE SECTION, FILE SECTION) so parser skipped all content.

**Solution:** Auto-detect section context:

```python
# In regex_extractor.py and ast_analyzer.py:

# Auto-detect file_section for FD entries
if code_line.strip().upper().startswith('FD '):
    if current_section is None:
        current_section = 'file_section'

# Auto-detect working_storage for 01-levels
if current_section is None and level == '01':
    current_section = 'working_storage'
```
