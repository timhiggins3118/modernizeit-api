## Quick Reference: Once EC2 is Live

### Step 1: SSH into EC2
```bash
ssh -i your-key.pem ubuntu@<EC2_PUBLIC_IP>
```

### Step 2: Upload deployment scripts
```bash
# On your local machine:
cd /Users/timhiggins/Desktop/desktop/Source/TransformationCode/code-transformation-modernizeit2/modernizeit-api
scp -i your-key.pem -r deployment ubuntu@<EC2_PUBLIC_IP>:~
```

### Step 3: Run setup script
```bash
# On EC2:
cd ~
chmod +x deployment/01_ec2_setup.sh
./deployment/01_ec2_setup.sh
```

### Step 4: Log out and back in
```bash
exit
ssh -i your-key.pem ubuntu@<EC2_PUBLIC_IP>
```

### Step 5: Upload API code
```bash
# On your local machine:
cd /Users/timhiggins/Desktop/desktop/Source/TransformationCode/code-transformation-modernizeit2/modernizeit-api
rsync -avz --exclude='.venv' --exclude='__pycache__' --exclude='*.pyc' \
  -e "ssh -i your-key.pem" \
  . ubuntu@<EC2_PUBLIC_IP>:/var/modernizeit/modernizeit-api/
```

### Step 6: Run deployment script
```bash
# On EC2:
cd /var/modernizeit/modernizeit-api
chmod +x deployment/02_deploy_api.sh
./deployment/02_deploy_api.sh
# (Ctrl+C after API test starts successfully)
```

### Step 7: Configure environment
```bash
nano /var/modernizeit/modernizeit-api/.env
# Update any production values (S3 buckets, API URLs, etc.)
```

### Step 8: Start service
```bash
sudo systemctl start modernizeit-api
sudo systemctl status modernizeit-api
tail -f /var/log/modernizeit/api.log
```

### Step 9: Test
```bash
curl http://localhost:8000/health
curl http://<EC2_PUBLIC_IP>:8000/health
```
