## The 4-Step Workflow Wizard

When user clicks an application, they enter:

| Step | Name | Our Flow |
|------|------|----------|
| 1 | Analysis | Code Analysis |
| 2 | O&T | Code Refactor + Dependency + Monolith |
| 3 | QA | Test Generation |
| 4 | Architecture | Architecture Analysis |

**Step 1 (Analysis) is the tricky one** - UI expects:
- File metadata (lines, paragraphs, confidence)
- Complexity rating
- AI-generated Business Purpose
- AI-generated Data Flows
